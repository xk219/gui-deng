# 夜行归灯

一个围绕**收集**的互动作品：冬夜雪原上，把散落的 6 根灯芯送回灯座，大灯亮起就算完成。

**一句话规则：影子只追光——你身上的灯芯越多，影子看得越远、跑得越快。**

直接玩：`index.html`（与 `style.css`、`game.js` 放在同一目录）。

## 玩法

- 方向键 / WASD 移动，手机用左下方向键；`P` 暂停。
- 走到灯芯上自动捡起，站到灯座（地图中央的石台）上自动存入。
- 灯座一次最多收 **3 根**，收完要冷却 **6 秒**才能再收。
- 存入 6 根 → 大灯亮起，影子消散，通关。

## 要做的选择

| 携带数量 | 你能看见 | 影子追你的半径 | 影子速度 |
|---|---|---|---|
| 0 根 | 小 | 看不见你 | 慢 |
| 1–2 根 | 变大 | 230–314 | 89–114 |
| 3 根 | 明显变大 | 396 | 139 |
| 6 根 | 最大 | 642 | 214（几乎追平你） |

灯座一次只收 3 根，所以**多带的那 3 根会陪你在灯座旁边等冷却**——等的时候影子还在靠近。
一次搬满 3 根更快，但要一路带着风险；一根一趟更安全，但要多走两趟。

## 反馈

- 拾取：灯芯炸开、提灯变亮、身上多一颗绕圈的小光点、清脆音效。
- 存入：灯座亮起一格、冷却环开始转、附近影子被光柱推开 3 秒、低音和弦。
- 被抢：影子红眼加速、画面震动、Toast 提示、灯芯掉回远处雪原。

## 实现

单页 Canvas + WebAudio，无第三方依赖、无外部图片音频。

- `game.js`：世界 1800×1300，摄像机跟随，光罩用径向渐变遮罩实现「只看见灯照到的地方」。
- 影子 AI：`wander`（缓慢游荡）→ `chase`（携带 > 0 且进入追猎半径）。
- 数值集中在 `lightRadius()` / `aggroRadius()` / `shadowSpeed()` 三个函数里，改数就能调难度。
